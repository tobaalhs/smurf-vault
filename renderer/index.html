Actualizar rangos sin abrir el juego

Para consultar todas tus cuentas a la vez, Smurf Vault usa la API oficial de Riot, que pide una API key gratuita.

  1. Entra a developer.riotgames.com con tu cuenta de Riot.
  2. Copia la Development API Key y pégala aquí. Dura 24 h; para una permanente, pide una Personal API Key ahí mismo.
¿Sin key? Con el cliente de LoL abierto, la cuenta en la que inicias sesión se actualiza sola.

Herramientas

Autoaceptar partidas

Acepta la partida por ti cuando sale en el cliente de LoL. Sigue funcionando con la bóveda bloqueada, mientras Smurf Vault esté abierto.

Esperar antes de aceptar

Con espera alcanzas a rechazar la partida tú si no quieres jugarla.

Solo hace lo mismo que apretar "Aceptar": no toca nada dentro de la partida.
